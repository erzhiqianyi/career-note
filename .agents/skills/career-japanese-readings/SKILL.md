# 日语资料注音

## 范围

生成日语资料时应直接在正文标记读音；本技能用于补充旧资料或检查新资料。格式为 `{漢字词|かな}`，例如 `{開発経験|かいはつけいけん}`、`{取り組み|とりくみ}`。读音跟随所在句子保存，同形异读按语境分别标记。网站设置开关只控制显示，关闭时仍保存读音。公开简历和投递用打印版不显示注音。

## 步骤

1. 从已配置的 Career Note MCP 读取用户指定的资料及现有版本。只处理日语正文，保留原文事实、来源和版本；职位原文和用户回答不可悄悄改写。
2. 只标注有把握的含汉字词，读音用假名。人名、公司名、地名、学校名没有可靠来源时不猜。履歴書姓名和住所的正式ふりがな字段只能由用户填写或确认。
3. 对可修订的草稿，保存包含注音的完整新版本并读回。不可原地修订的资料，给出带注音的修订稿，等待用户要求创建新版本；不要覆盖历史材料、原回答或职位来源。
4. 说明哪些文本已保存、哪些只是建议，以及任何仍需确认的读音。不要调用旧的 `career_save_readings` 词表接口。

## 连接

使用用户已配置的 Career Note MCP 和浏览器 OAuth 授权。没有连接时可提供带 `{漢字词|かな}` 标记的修订文本，不声称已保存。
