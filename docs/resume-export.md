# 日本向け応募書類の作成と出力

応募書類は会社ごとに準備する。

1. 「企業」で応募先を開き、「準備資料」から AI Agent に作成を依頼する。
2. Agent は応募先と事実資料に基づき、履歴書と職務経歴書をそれぞれ独立した `materials` レコードとして保存する。既存版を上書きしない。
3. 保存された資料を開き、内容と資料作成後のプロフィール・求人更新を確認する。
4. 「作成済みの応募書類をプレビュー・印刷」から独立したプレビューページ（`#documents/print/:id`）でその版を確認し、印刷先を PDF、用紙を A4、倍率を 100% にして保存する。ブラウザーのヘッダー・フッターは無効にする。

個人プロフィールと個別履歴書の一覧には印刷入口を置かない。会社に紐づいた履歴書・職務経歴書の詳細だけに表示する。未生成の資料に対して印刷や自動的な本文組み立ては行わない。

## 書式と生成時の責任

2026-09-22 に確認した公式資料：

- [ハローワークの応募書類作成ガイド](https://www.hellowork.mhlw.go.jp/member/career_doc01.html)
- [厚生労働省履歴書様式例・A4](https://www.hellowork.mhlw.go.jp/doc/kouroushourirekishoA4.pdf)
- [職務経歴書の作成ガイド](https://www.hellowork.mhlw.go.jp/doc/oubosyorui_pamphlet_02.pdf)

企業指定の書式がある場合はそちらを優先する。履歴書は厚生労働省様式の項目構成を参考に表形式で生成する。性別は任意で、配偶者・扶養家族・通勤時間を追加しない。職務経歴書は氏名・日付・職務経歴を含む自由書式。目安は A4 縦 1〜2 枚程度だが、長文を自動切り捨てしない。

本文は応募用の草稿として保存し、出典・内部説明・欠落項目の一覧は `sourceNotes` に分離する。未知の事実を補完してはならない。既存の Markdown 本文は自動変換・再生成せずそのまま印刷するため、旧資料の構成が異なる場合は新しい版を準備する。

PDF には保存済みの `content` のみを使用する。`sourceNotes`、ワークスペースの操作ボタン、現在のプロフィール情報は含めない。生成日の氏名・日付・内容を印刷時に差し替えない。生成後の修正は新しい版として保存する。

PDF はブラウザーの印刷機能で生成する。長い文章や表がある場合の実際の改ページは印刷プレビューで確認する。サーバー生成、DOCX 出力、応募先への送信は行わない。

プレビューページは本文・印刷操作だけを表示し、原文の詳細や出典メモを同時表示しない。戻る操作で元の保存済み資料に戻る。URLからの再表示にも対応する。
