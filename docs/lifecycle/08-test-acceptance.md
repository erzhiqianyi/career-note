# 08 テスト計画・受入判定

状態：実行可能な自動テストと、今後も使う受入試験表。最新結果は [検証記録](../verification.md)。

## テスト階層

| 層 | 対象 | 手段 |
| --- | --- | --- |
| 単体 | JWT 検証、アカウント許可、アーカイブ整合性 | Node.js test runner |
| 結合 | Worker と D1、保存・不正アクセス | Miniflare、架空データ |
| 静的 | TypeScript、文書リンク、公開ファイル | typecheck / check:docs / check:public |
| ビルド | フロント・サーバーバンドル | vinext build |
| システム | クリーン取得から起動、再起動、CLI | ローカル HTTP と導入スモーク |
| 受入 | 実利用者の操作と Google ログイン | 利用者が手順を実施し結果記録 |

## 受入試験ケース

| ID | 条件・操作 | 期待結果 | 対応要求 |
| --- | --- | --- | --- |
| UAT-01 | 空の保存先で npm ci / dev | 画面と API が応答し、サンプル以外の実データがない | FR-09 |
| UAT-02 | 架空求人を登録→状況更新→再起動 | 情報と履歴を確認できる | FR-01,02 |
| UAT-03 | 求人→資料を別パッケージで preview / import | 企業との関連を確認できる。未完タスクを偽って完了しない | FR-04,06 |
| UAT-04 | 質問集→自分の回答→添削を別保存 | 元回答を残し、添削の対象が一致する | FR-05 |
| UAT-05 | 許可 Google / 許可外 / ログアウト / 再読込 | 許可対象だけが表示可能。失敗時に既存データを残さない | FR-07 |
| UAT-06 | 求人サービスを追加・編集→再読込 | 設定が保持される | FR-08 |
| UAT-07 | 停止後バックアップ→別保存先で復旧 | 対象求人とプロフィールの内容が一致する | NFR-01,03 |
| UAT-08 | キーボード、狭い画面、200% 拡大、長文 | 操作と主要情報を見失わない | NFR-07 |

## 実行記録の形式

ケース ID、コミット、日時、OS、Node.js、保存先が架空か、前提、実結果、合否、証跡、担当、残課題を書く。失敗を修正したら対象試験を再実行する。自動テストの成功を Google 実ログインや画面 UAT の代わりにしない。

## 判定 G4

個人データ漏えい、未認証での strict データアクセス、既存データの破壊は公開停止。文書で説明されたプレビュー制約は、利用目的を満たすか所有者が判断する。残課題は責任者・対処時期・回避策付きで残す。承認欄が空なら受入済みではない。
