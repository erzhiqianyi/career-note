# 既知の制約とロードマップ

v0.1.0 は個人向けローカルプレビュー。機能の存在と、すべての品質条件を満たしたことは別。

| 項目 | 現状 | 回避・次の対応 |
| --- | --- | --- |
| import 原子性 | 逐次書込み。途中失敗で前半が保存され得る | 事前バックアップ、分割、ID 読戻し。将来バッチ原子化 |
| preview の検証 | 保存時の全検証と同等ではない | 成功を完全な保証としない。検証ロジック共通化を計画 |
| 新規求人と資料の同時 import | 取込開始時点の求人で関連を見る | 求人→資料の順に別パッケージで取込 |
| ユーザー分離 | 検証済み Google UID ごとに業務データを分離 | 新規ユーザーは空の状態。公開運用の構成は[デプロイ手順](deployment.md)を参照 |
| 同時編集 | 全更新の競合を原子的に防げるわけではない | 1 人で利用。完全な競合制御を計画 |
| テスト範囲 | Worker と認証の主要条件を自動試験 | 全機能 UAT / 実 Google OAuth は導入環境で確認 |
| 依存監査 | 既知の上流依存の指摘が残る | [検証記録](verification.md)の監査結果を確認。公開ホスティングに使わない |
| UI | 主に中国語。一部アクセシビリティ・lint 指摘が残る | 日本語化と該当箇所の改善を別 Issue で実施 |
| DB 移行 | 初回テーブル作成のみ。バージョン付き移行なし | DB 変更前に専用設計と復旧試験 |
| 全件取得 | state は全件返却 | 個人規模で利用。性能計測とページングを検討 |
| AI 処理 | 外部 Agent の手動実行が必要 | 依頼と処理済み成果を区別 |
| オフライン | 初回依存取得・Google・外部 Agent にネットが必要 | 認証なしの保存機能と外部機能を区別 |
| Agent 接続 | MCP OAuth のみ。手動トークン発行は廃止。ホスト型 Agent（claude.ai / ChatGPT）はトンネルか公開デプロイが必要 | `npm run dev:tunnel` で API だけ一時公開（strict 必須）。恒久的な公開は[Cloudflare デプロイ](deployment.md)（Pages + Worker、strict 必須） |
| CLI 認証 | Google モードでは `scripts/career-data.mjs` に渡すトークンがない | off モードで使う。必要なら CLI 向けの認可フローを別途企画 |

## 優先順位案

P0：個人情報保護と保存整合性。P1：import 検証・原子化、復旧試験の拡充。P2：日本語 UI、操作品質、データ量試験。P3：利用者別分離や同期は必要性を確認して別途企画する。

ロードマップは納期の約束ではない。着手判断・担当・費用は Issue と計画に記録する。
