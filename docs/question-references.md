# 練習質問の番号と Agent 連携

保存済みの練習質問には、サーバーが `Q123` 形式の番号を付けます。質問一覧と詳細に同じ番号を表示し、詳細の番号ボタンからコピーできます。iOS では次回の同期で取得し、オフラインでもキャッシュ済みの番号を表示します。未同期の旧データとアプリ内蔵の固定問題には番号を表示しません。

別の Agent に「Career Note の Q123 を取得して、参考回答を確認してください」と伝えると、Career Note MCP に接続済みで `career:read` の権限がある Agent は `career_get_question({"number":"Q123"})` で取得できます。番号は認証済みアカウント内の参照で、公開リンクや認証情報ではありません。質問、題組と会社の ID、本人の回答履歴、関連する点评を返します。原回答と参考回答は別のフィールドです。

編集する Agent は返された `questionSetId` と `question.id` を使い、既存の `questionSetPatches` → preview → import → 読み戻しの手順を守ります。番号による取得だけでは編集しません。本人の回答を参考回答で上書きしません。

番号は題組 ID と質問 ID に対応し、タイトル変更、並べ替え、全体更新、部分更新でも変わりません。入力に含まれる `questionNumber` は採用せず、サーバーの対応表を使います。削除した質問の番号を別の質問に再利用せず、削除済みの番号は 404 を返します。別アカウントでは同じ番号が別の質問を指すため、Agent は接続先を確認してください。

REST: `GET /api/career/questions/by-number?number=Q123`（`career:read` 必須）。`number=123` も指定可能です。新しい Worker と iOS アプリへの更新、および MCP ツール一覧の更新が必要です。
