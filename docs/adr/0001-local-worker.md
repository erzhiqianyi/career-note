# ADR-0001: Node.js とローカル Worker を唯一の通常経路にする

日付：2026-09-12。状態：採用。現行設計を公開時に記録したもの。

## 背景

Python CLI と Worker に独立した保存先があると、CLI で保存しても画面で見えない。利用者ごとの絶対パスや複数ランタイムは、初回導入を難しくする。

## 決定

Node.js で起動・アーカイブ・CLI・既定テストを行う。Web と CLI は同じ Worker HTTP API を使う。ローカル D1 の親ディレクトリを環境変数で指定し、ソース外に保存する。Google は任意の入口認証とする。

## 比較した案

Python と Worker の両対応は移行柔軟性があるが、二重保守とデータの混同が残る。クラウド DB 必須は配布しやすい一方、個人データの預託と運用設定が増える。本案はローカル導入を優先した。

## 結果・負債

Python は公開版から除外。新規プロジェクトとして開始し、旧データ互換・移行は実装しない。Worker import の完全な原子性や検証の不足はこの選択で解消しないため、別の改善として追跡する。複数ユーザー向けサービスへ拡張する場合は、新しい ADR を作成する。
